# Package conventions — @design-schema/rn (React Native)

Versions (2026-09-11): React Native 0.87 (strict TypeScript API) · React 19.3 (`ref` is a prop, no `forwardRef`) · TypeScript 7.0 (`isolatedDeclarations`, built by tsdown 0.23) · Storybook 10.6 CSF3 (`@storybook/react-vite` on react-native-web 0.21) · Vite 8.3 · Jest 30 with `@react-native/jest-preset` 0.87 and `@testing-library/react-native` 13 · react-native-svg 15.

Read this instead of the whole package. Open at most two files if a detail is missing: `packages/rn/src/index.ts` (exports) and the one existing component closest to what you are writing.

- **Files.** `packages/rn/src/<Name>.tsx` exporting a named function component and its types; `<Name>.stories.tsx`. `index.ts` gets `export { <Name> } from './<Name>'; export type { … } from './<Name>';` in the existing style.
- **Tokens.** `const { tokens: t, mode } = useTheme();` from `./theme`. Keys are camelCase (`t.colorActionPrimaryBackground`, `t.spaceSm`, `t.fontSizeMd`, `t.radiusMd`, `t.borderWidthFocus`, `t.opacityDisabled`, `t.motionDurationFast`); dimensions and durations are numbers, colors strings, `fontFamily` a string. Interpolated bindings use a lookup table keyed by the enum value (`const TONE = { info: { background: 'colorStatusInfoBackground', … } } as const` then `t[TONE[tone].background]`). Helpers: `toFontWeight(t.fontWeightMedium)` (RN wants a string), `toLineHeight(t.fontLineHeightNormal, t.fontSizeMd)` (absolute), `toEasing(t.motionEasingStandard)` (bezier array → `Easing.bezier`), `useReducedMotion()`. No literals for size/color/duration (`tools/lint_literals.py` flags bare numbers on size properties); `0`, `1`, `2` and percentages are allowed; anything else needs `// literal-ok: reason`.
- **Overrides.** `overrides?: Partial<Record<OverridableBinding, TokenRef | undefined>> | undefined` (`TokenRef`, `resolveToken` from `@design-schema/tokens`): `resolveToken(t, ref)` replaces the binding's default in the style object. No `style` prop is accepted. Locked bindings excluded.
- **Refs.** React 19: `ref` is an ordinary prop, never `React.forwardRef`. A component that exposes its root declares `ref?: React.Ref<ViewInstance> | undefined` (the root's instance type) in its props and passes it through (`ref={ref}`, or `useImperativeHandle(ref, …)` when an inner ref owns the root). `Card` and Slider's thumb predate this and still wrap `forwardRef`; they are rewritten at their next regeneration, not by hand.
- **Strict flags.** TypeScript 7 with `isolatedDeclarations`: every exported symbol carries an explicit type annotation, and no export type is inferred — components return `React.JSX.Element` (`| null` when they can render nothing), contexts `React.Context<Value>`, hooks declare return types (`PanResponderInstance['panHandlers']` for pan handlers). `exactOptionalPropertyTypes`: optional props are `name?: T | undefined` (function props `onX?: ((…) => void) | undefined`); a value that may be `undefined` passed to a React Native or react-native-svg prop that does not accept it is asserted (`strokeWidth={strokeWidth!}`). `noUncheckedIndexedAccess`: an index read (`items[i]`, `text[0]`) is `T | undefined` — guard it, or assert with `!` where the index is known to exist. `verbatimModuleSyntax`: type-only imports use `import type` or inline `type` specifiers.
- **Spacing between siblings** is never a margin: `Stack gap` (`t.layoutGap*`), `Box`/`Card` `inset` (`t.layoutInset*`), `Container` gutters. A resolved token path ending in `.default` drops it (`t.colorBackground`).
- **Styles** are `StyleSheet.create` or inline objects built from `t` in a `useMemo`; there is no cascade, so every binding is applied explicitly. Text typography comes from the system `Text` where possible; `Text` provides `TextNestingContext` (true when nested) so inline children inherit.
- **Types.** React Native 0.87 ships the strict TypeScript API by default (`types_generated/`, the one `react-native` resolves to). Import instance types for refs, never component types: `useRef<ViewInstance>(null)`, `TextInputInstance`, `ScrollViewInstance`, `SwitchInstance`, `HostInstance` for a generic native element; a `ref` prop is `React.Ref<ViewInstance>`. Event types are whole events: `TextInputKeyPressEvent`, `TextInputFocusEvent`, `LayoutChangeEvent` (no `NativeSyntheticEvent<…Data>` wrapping). Viewability tokens are `ListViewToken`. Animated style objects are `Animated.WithAnimatedValue<ViewStyle>`. `StyleSheet.absoluteFill` is the object (`absoluteFillObject` is gone). `ViewStyle`/`TextStyle` are read-only: build a style in one literal or type a local as `{ -readonly [K in keyof ViewStyle]: ViewStyle[K] }` before assigning to it. `FlexAlignType` is `NonNullable<ViewStyle['alignItems']>`. `findNodeHandle` returns `number | null | undefined`; guard with `!= null`. FlatList's `List*Component` props take an element or `undefined`, not `null`.
- **Accessibility.** `accessibilityRole`, `accessibilityLabel`, `accessibilityHint`, `accessibilityState` (`disabled`, `checked` incl. `'mixed'`, `expanded`, `selected`, `busy`), `accessibilityValue` for ranges, `accessibilityLiveRegion` (Android) plus `AccessibilityInfo.announceForAccessibility` (iOS) for announcements. The `role` prop (typed `Role`, available since RN 0.73 and the preferred form on ≥ 0.87) where a web landmark/semantic exists; keep `accessibilityRole` for the values `Role` lacks (`search`) and for react-native-web, which maps both to the same ARIA role. Decorative glyphs: `accessibilityElementsHidden` and `importantForAccessibility="no"`. `disabled` is conveyed via `accessibilityState.disabled` plus a press guard — do not pass `disabled` to `Pressable` (it removes focus); the native `Switch` is the exception.
- **Focus-visible** is tracked by hand on `Pressable` (`onFocus`/`onBlur` state) and drawn as a border of `t.borderWidthFocus` in `t.colorBorderFocus`; targets reach `t.sizeTargetMin`/`t.sizeTargetComfortable` with `hitSlop` when the visual box is smaller. `Text` and native `Switch` have no focus events — acknowledged limit.
- **Forms.** Fields register with `FormContext` (`useFormContext()`): `{ name, label, getValue, validate, focus }`; `getValue` returns `string | boolean | undefined`. Precedence: `error` prop → `required` (`copy.required`) → `invalid` (`copy.invalid`). `validate: blur` means on-change for toggles. Focus on failed submit uses `AccessibilityInfo.setAccessibilityFocus(findNodeHandle(ref))`.
- **Composition.** Use `Button` (`leadingIcon`/`trailingIcon`, `iconOnly`), `Link`, `Text`, `Icon` from the package; never restyle a child. Because there is no `currentColor`, pass the foreground token to `Icon`'s `color` prop.
- **Animation.** `Animated` with `useNativeDriver: false` for layout props (react-native-web has no native driver); skip when `useReducedMotion()` is true.
- **Dev warnings** use `__DEV__`.
- **Stories.** Storybook 10 CSF3 with `@storybook/react-vite` under react-native-web, `title: '<Name>/React Native'`, wrapped by the package decorator (`withTheme` from `decorators.tsx`, which follows the Mode toolbar), `Default` plus one story per enum value named `<Prop><Value>`, plus notable states. Demos in `packages/rn/demo/` with `title: 'Demo/<Name>/React Native'`. CSF factories are not used.
- **Tests.** Jest 30 with `@react-native/jest-preset` (`packages/rn/jest.config.cjs`; RN's test renderer wants Jest, so this package alone does not use Vitest) and `@testing-library/react-native` 13's synchronous `render`/`fireEvent`; behavior scenarios become `<Name>.test.tsx` beside the component.
- **Testability hook.** The root view carries `testID="<Name>"`. Older components lack it; add it to any file you touch.
- **Dependencies.** `react-native-svg` is the only permitted third-party runtime dependency (Icon uses it; nothing else may add one). Everything else is core React Native: no gesture-handler, no reanimated, no community pickers. A new entry in packages/rn/package.json fails review.
- **Parts and overrides.** `testID="<Name>.<part>"` uses anatomy names verbatim. An override for a composed child's binding is passed to that child's `overrides` prop (Fieldset → Stack `gap`, Divider → Text `fontSize`, Alert → Icon `color`/`size`); never resolve a token on the child's behalf.
