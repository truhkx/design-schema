- Form: FormContextValue is not named in the web spec; only the RN notes list the context shape ({ register, unregister, submit, errors, validateMode, submitFailed, disabled, focusField }). - Form: the FailedSubmit story needs a play function, but no story in the package uses one and storybook/test is not a declared dependency. I used canvasElement.querySelector('form').requestSubmit() plus one animation frame. The doc does not say which test utilities a play function may import.
