# Package conventions — @design-schema/rn (React Native)

Read this instead of the whole package. Open at most two files if a detail is missing: `packages/rn/src/index.ts` (exports) and the one existing component closest to what you are writing.

- **Files.** `packages/rn/src/<Name>.tsx` exporting a named function component and its types; `<Name>.stories.tsx`. `index.ts` gets `export { <Name> } from './<Name>'; export type { … } from './<Name>';` in the existing style.
- **Tokens.** `const { tokens: t, mode } = useTheme();` from `./theme`. Keys are camelCase (`t.colorActionPrimaryBackground`, `t.spaceSm`, `t.fontSizeMd`, `t.radiusMd`, `t.borderWidthFocus`, `t.opacityDisabled`, `t.motionDurationFast`); dimensions and durations are numbers, colors strings, `fontFamily` a string. Interpolated bindings use a lookup table keyed by the enum value (`const TONE = { info: { background: 'colorStatusInfoBackground', … } } as const` then `t[TONE[tone].background]`). Helpers: `toFontWeight(t.fontWeightMedium)` (RN wants a string), `toLineHeight(t.fontLineHeightNormal, t.fontSizeMd)` (absolute), `toEasing(t.motionEasingStandard)` (bezier array → `Easing.bezier`), `useReducedMotion()`. No literals for size/color/duration (`tools/lint_literals.py` flags bare numbers on size properties); `0`, `1`, `2` and percentages are allowed; anything else needs `// literal-ok: reason`.
- **Overrides.** `overrides?: Partial<Record<OverridableBinding, TokenRef>>` (`TokenRef`, `resolveToken` from `@design-schema/tokens`): `resolveToken(t, ref)` replaces the binding's default in the style object. No `style` prop is accepted. Locked bindings excluded.
- **Spacing between siblings** is never a margin: `Stack gap` (`t.layoutGap*`), `Box`/`Card` `inset` (`t.layoutInset*`), `Container` gutters. A resolved token path ending in `.default` drops it (`t.colorBackground`).
- **Styles** are `StyleSheet.create` or inline objects built from `t` in a `useMemo`; there is no cascade, so every binding is applied explicitly. Text typography comes from the system `Text` where possible; `Text` provides `TextNestingContext` (true when nested) so inline children inherit.
- **Accessibility.** `accessibilityRole`, `accessibilityLabel`, `accessibilityHint`, `accessibilityState` (`disabled`, `checked` incl. `'mixed'`, `expanded`, `selected`, `busy`), `accessibilityValue` for ranges, `accessibilityLiveRegion` (Android) plus `AccessibilityInfo.announceForAccessibility` (iOS) for announcements, `role` (RN ≥ 0.74) where a web landmark/semantic exists. Decorative glyphs: `accessibilityElementsHidden` and `importantForAccessibility="no"`. `disabled` is conveyed via `accessibilityState.disabled` plus a press guard — do not pass `disabled` to `Pressable` (it removes focus); the native `Switch` is the exception.
- **Focus-visible** is tracked by hand on `Pressable` (`onFocus`/`onBlur` state) and drawn as a border of `t.borderWidthFocus` in `t.colorBorderFocus`; targets reach `t.sizeTargetMin`/`t.sizeTargetComfortable` with `hitSlop` when the visual box is smaller. `Text` and native `Switch` have no focus events — acknowledged limit.
- **Forms.** Fields register with `FormContext` (`useFormContext()`): `{ name, label, getValue, validate, focus }`; `getValue` returns `string | boolean | undefined`. Precedence: `error` prop → `required` (`copy.required`) → `invalid` (`copy.invalid`). `validate: blur` means on-change for toggles. Focus on failed submit uses `AccessibilityInfo.setAccessibilityFocus(findNodeHandle(ref))`.
- **Composition.** Use `Button` (`leadingIcon`/`trailingIcon`, `iconOnly`), `Link`, `Text`, `Icon` from the package; never restyle a child. Because there is no `currentColor`, pass the foreground token to `Icon`'s `color` prop.
- **Animation.** `Animated` with `useNativeDriver: false` for layout props (react-native-web has no native driver); skip when `useReducedMotion()` is true.
- **Dev warnings** use `__DEV__`.
- **Stories.** CSF3 with `@storybook/react` under react-native-web, `title: '<Name>/React Native'`, wrapped by the package decorator (`withTheme` from `decorators.tsx`, which follows the Mode toolbar), `Default` plus one story per enum value named `<Prop><Value>`, plus notable states. Demos in `packages/rn/demo/` with `title: 'Demo/<Name>/React Native'`.
- **Testability hook.** The root view carries `testID="<Name>"`, and every anatomy part that is not already reachable by role or text carries `testID="<Name>.<part>"` (the schema's anatomy name, e.g. `testID="Checkbox.description"`), which is how the behavior gate (`tools/behavior_tests.py`) locates parts. Older components lack both; add them to any file you touch.
