# Gaps reported while generating DataGrid for web

Each entry is a place the doc made the generator guess. Fix the doc, re-run parse, regenerate.

## 2026-09-10 14:12 — round 1

- Input/NumberInput/Select/DatePicker/Checkbox have no `size`/hideLabel prop and omit an external `aria-describedby` from their public types, but the doc calls for editors rendered with 'label visually hidden, size sm'. Since children may never be restyled from outside, editors render with their normal, full-size, visible label inside the cell (expanding the row while editing) rather than the hidden-label compact form the doc describes.
- Because those field components can't take an external aria-describedby, the 'Editing {column}. Enter to save, Escape to cancel.' copy is announced through the shared status-bar/live-region on edit start instead of being wired directly to the editor field.
- Select/DatePicker/Checkbox editors commit immediately on change (treated as discrete pickers); text/number editors commit on Enter/F2/blur. The schema doesn't address commit timing for non-text editors, so this split is an implementation choice.
- F2's 'toggles between editing and navigating' (the APG cursor-vs-cell distinction) is simplified to 'F2 commits and returns to navigation', since the composed Input/NumberInput controls have no internal edit-cursor-vs-cell-navigation mode to toggle.
- The keyboard model's Tab row says Tab always leaves the grid (one tab stop) even from a cell with an open editor, which contradicts the Behavior prose's 'Tab commits and moves right.' Implemented per the keyboard array (authoritative): Tab is never intercepted; committing on tab-out happens via blur instead.
- `selectable: 'cell'` has no dedicated key in the keyboard model to confirm a cell selection (Space is scoped only to row/range), so selection is implemented as always following the focused cell.
- Shift+Space ('selects the row') is interpreted as extending the row selection from the last anchor to the current row (shift-click-style range); Ctrl+Space ('the column in range mode') is interpreted as selecting the full loaded column. Neither is spelled out beyond the plain-Space toggle.
- Range-selection behavior on plain (non-Shift) cell movement isn't specified beyond 'extends with Shift+arrows or drag'; implemented as collapsing/resetting the anchor to the newly focused single cell, matching common spreadsheet UX.
- Pinned columns are assumed contiguous at the start/end of the `columns` array; the auto-added selection checkbox column never pins (the schema gives it no such switch), so it scrolls out of view even when data columns are pinned.
- `rowCount` vs. `data`-as-a-window has no defined offset in the schema; this implementation assumes `data` always starts at index 0 of the full set and requests more via `onRangeNeeded` as the loaded window's end is approached.
- `height: viewport` fills 100% of whatever block-size the parent budgets (flex/grid layout) since the schema gives DataGrid no page-rhythm token analogous to Table's `layout.gap.section`-based viewport cap; the exact fill mechanism is left to the consuming page.
- Row height for virtualization math is measured via ResizeObserver on a hidden sizer element (rather than hardcoded per density), since compact/comfortable row heights are theme tokens the JS layer can't otherwise read — keeps the math theme-agnostic.
- Default column width (160, matching the schema's own example) and the resize keyboard step (16px) aren't specified by the schema; chosen pragmatically.
- The range-selection overlay is computed from the two endpoint cells' rendered bounding boxes; if either endpoint has scrolled outside the current virtualization window, the overlay isn't drawn until it's back in view.
- Enter's 'on a cell containing a control: activates it' is implemented generically for custom `column.render` content (focuses+clicks the first focusable descendant); it doesn't apply to the built-in selection checkbox column, which is only reachable via Space.
- Added an undocumented `container?: HTMLElement` prop, forwarded to the composed Select/DatePicker editors' own `container`, per the package's portal convention that every portaled overlay accepts a container override.
- Mouse drag-to-select a range is implemented via mouseenter-while-dragging; the schema only says 'drag rectangles' without further detail.

## 2026-09-10 19:16 — round 1

- DataGrid: `resizeStep` (space.4) is a style token but there's no CSS API to read a resolved custom-property length from JS without measuring; fixed the pre-existing implementation to measure it via a hidden 1px-tall sizer element sized by `inline-size: var(--ds-data-grid-resize-step)` (same pattern as rowHeight), instead of a hardcoded 16px constant, so `overrides.resizeStep` now actually changes the Shift+Arrow resize increment.
- DataGrid: Delete/Backspace clears editable cells by firing onCellChange with value: undefined — the schema says 'clears the value' but doesn't specify whether that means undefined, empty string, or omission from the payload; chose undefined since the column model documents that as 'omitted'.
- DataGrid: resizable columns pin the select-all/select checkbox column to width var(--size-target-min) and never let it participate in `pinned` styling since the schema gives it no such prop; treated it as always effectively pinned-start (per the 'selection column is always pinned start' line) but without the pinned-shadow visual since it has no adjacent pinned sibling by default.
- DataGrid: `copy.position` is documented as the status bar's per-cell text but is explicitly 'not announced' — implemented it as unused in the live region, and the status bar instead shows row/selection counts; there's no story exercising the position text directly since the spec gives no trigger for surfacing it over the count text.

## 2026-09-16 11:39 — round 1

- DataGrid: onCellChange payload types `value`/`previous` as `string | number | boolean`, but the Delete/Backspace rule fires with `value: undefined` (and a cleared NumberInput or an unset cell also yields undefined); typed both as `DataGridCellValue | undefined`.
- DataGrid: onEditStart is `cancelable` with 'returns false or calls preventDefault() on the event it receives', but its positional payload is (rowId, column) with no event; only `return false` refuses on web.
- DataGrid: Escape 'clears a range selection' but onSelectionChange's union has no empty shape; the range is cleared without firing onSelectionChange.
- DataGrid: onCellChange 'fired when an edit commits' does not say whether an unchanged value commits; it fires only when the value differs (Object.is) from the previous one, but validate still runs.
- DataGrid: onRangeNeeded gives no size for the requested window; it asks for one visible page: start = data.length, end = min(rowCount - 1, data.length + pageSize - 1). It is checked on scroll and keyboard moves only (fires: user), never on mount.
- DataGrid: the caption composes Heading but no heading level is specified; used level 2, size md, with captionSize/captionWeight forwarded as the Heading's fontSize/fontWeight overrides (defaults font.size.md / font.weight.semibold) and marginBlockEnd space.0.
- DataGrid: the selection column has no width binding; used calc(size.target.min + 2 × cellPaddingInline), and pinned-start offsets add it via calc().
- DataGrid: rowHeight is locked and 'virtualization measures one rendered row', but before the first measurement (and always in jsdom) the window is unknown; up to 50 rows render until a row is measured, and offsets use calc(index × row-size var) so positions are correct before measuring. The density row size lives in an internal `--ds-data-grid-row-size` custom property that is not an override hook.
- DataGrid: column resize says the separator (role=separator, aria-valuenow) is 'adjustable with arrow keys', but the grid is one tab stop and the keyboard table puts resizing on Shift+ArrowLeft/Right of the header cell; the separator is pointer-only (not focusable) and keyboard resizing goes through the header cell, firing onColumnResize on Shift keyup. resizeStep and the minimum width (size.target.min, unless minWidth) are measured from hidden token-sized probes.
- DataGrid: `abbr` is 'the spoken form' but a div columnheader has no abbr semantics; non-sortable headers render the visible header aria-hidden plus a visually hidden abbr. Sortable headers keep copy.sortAscending/Descending as the Button's accessible name and ignore abbr.
- DataGrid: the sortButton part must carry data-part for the behavior locator, but Button overwrites data-part with 'container'; the part is a wrapping span that owns the click handler, so the click bubbles from the Button. Likewise, clicking the selectCell/selectAllCell container toggles, not only its Checkbox.
- DataGrid: headerWeight/headerSize style the header part, but the sortable header text is the composed Button; they are forwarded to the Button's fontWeight/fontSize overrides (plus paddingInline space.0 so the text lines up with the cells).
- DataGrid: statusBarSize is forwarded to the status bar Texts' fontSize override; statusBarPadding is also used as the gap between status-bar items (no gap binding exists), and the status-bar copy has no separator between row count, selection count, scroll hint and position.
- DataGrid: cellMutedColor (color.foreground.muted, part cell) has no stated use; applied to existing body cells while `loading`.
- DataGrid: Behavior says the status bar's role=status is the live region, yet copy.position is shown there and 'not announced'; only a live span (loading / invalid / sort, selection, copy, editing announcements) is role=status. Row count, selection summary, scrollHint and position sit beside it, outside the live region. With showStatusBar false the bar stays in the DOM, visually hidden, holding only the live span.
- DataGrid: copy.scrollHint has no stated trigger; shown in the status bar while the scroll region overflows horizontally and has not been scrolled sideways.
- DataGrid: row mode pointer selection is 'Shift/Ctrl row selection' with no detail; Shift+click on a body cell extends from the row anchor (the last toggled row) and Ctrl/Cmd+click toggles, while a plain click only moves focus. Shift+Space extends the anchor-to-focus span into the existing selection instead of replacing it.
- DataGrid: Control+a / Control+c and the Ctrl modifiers of Home/End/Space are written as Control only; on web Cmd (metaKey) is accepted too.
- DataGrid: in range mode, a plain arrow collapses the range and fires onSelectionChange only when a range exists; after Escape clears it, arrows only move the anchor.
- DataGrid: cell mode fires onSelectionChange on every move to a body cell (selection follows focus). There is no visual style for the selected cell beyond the focus ring (no binding), so it shows only while the grid has focus.
- DataGrid: when `selectable` is none or cell, Space is not bound, so it counts as a printable character and opens a text/number editor seeded with a space.
- DataGrid: pinned columns vs. the range fill: the fill is drawn under the rows (opaque rangeBackground keeps the contrast pair exact), so opaque pinned cells and a hovered row cover it; the range border overlay is drawn above.
- DataGrid: the editor 'overrides for inset zero' has no per-editor mapping; used paddingInline/paddingBlock space.0 (Input, NumberInput, DatePicker) and triggerPaddingInline/triggerPaddingBlock (Select). Checkbox has no inset binding and gets none.
- DataGrid: focus-visible for the active cell: a div focused by a click does not match :focus-visible, so the inset cell ring uses :focus-within on the grid (the ring is the non-hover signal); the grid's own outline stays on :focus-visible.
- DataGrid: `height: viewport` sets the scroll region to calc(100vh − 2 × layout.gap.section), which with the caption and status bar makes the whole component taller than the viewport; the spec does not say whether they are included.

## 2026-09-17 14:06 — round 1

- DataGrid: the anatomy names no sort-direction indicator and no copy string for one, but aria-sort alone leaves sighted users nothing to read the direction from; chose a chevron-up/chevron-down Icon as the sort Button's trailingIcon.
- DataGrid: `columnWidth` is a token binding while `width`/`minWidth` are pixel numbers, so a default-width column has no pixel width at render. Emitted CSS calc() for grid-template-columns, pinned offsets and the range overlay, and start a resize from the header cell's measured rect — but the resizeHandle separator's `aria-valuenow` (required by the web platform notes) is omitted until the column has an explicit or resized width, since the token's pixel value is unknown at render.
- DataGrid: `defaultSort` says the grid sorts `data` itself when `rowCount` is not set; it does not say whether a controlled `sort` also sorts. Chose internal sorting only in the uncontrolled case (a controlled caller owns the order), as Table.
- DataGrid: `captionLevel` says the size is captionSize regardless of level, but captionSize (font.size.md) is also Heading's default size for level 6 only. Chose `size="md"` plus the captionSize/captionWeight overrides forwarded to the Heading, so the level never moves the visual size.
- DataGrid: aria-rowcount — the spec does not say whether the header row counts. Chose `rowCount + 1` to match the header row carrying aria-rowindex=1 and body rows starting at 2.
- DataGrid: `height: viewport` says it sizes the whole component, while `fixedHeight` is described as 'the grid height'. Chose to size the root for both and let the scroll region take what the caption and status bar leave.
- DataGrid: the keyboard table binds Space only for row/range, and the guidance says Space is never an edit trigger in none/cell mode — but typing a printable character opens the editor. Chose to exclude ' ' from the type-to-edit path so Space does nothing at all in none/cell.
- DataGrid: `cell` mode fires onSelectionChange on every move to a body cell; the spec does not say what a click on the selection column, a header cell, or a cell in a not-yet-loaded row does. Chose to fire only for body data cells, on both keyboard moves and pointer clicks.
- DataGrid: copy.copied is announced only after navigator.clipboard.writeText resolves; the spec does not say what to announce when the clipboard write is refused (no permission, or no clipboard API). Chose to announce nothing.
- DataGrid: `abbr` is documented as the spoken name of a non-sortable header, and a sortable header's name stays sortAscending/sortDescending built from `header` — so `abbr` on a sortable column is silently unused. Implemented as written; the docs may want to say that explicitly or fold abbr into the sort copy.
- DataGrid: Delete/Backspace over a multi-cell selection fires one onCellChange per editable cell, but the spec gives no ordering. Chose row-major (rows in display order, columns in `columns` order).
- DataGrid: the status bar shows row count, selection count, scroll hint and position, but the spec does not order them or say where the live span sits among them. Chose live span + counts at the start, scroll hint and position at the end.
