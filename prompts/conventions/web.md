# Package conventions — @design-schema/react (web)

Read this instead of the whole package. Open at most two files if a detail is missing: `packages/react/src/index.ts` (exports) and the one existing component closest to what you are writing.

- **Files.** `packages/react/src/<Name>.tsx`, `<Name>.css`, `<Name>.stories.tsx`. Component is a named export `forwardRef` function; types exported alongside (`<Name>Props`, `<Name><Enum>` unions). Add `export { <Name> } from './<Name>'; export type { … } from './<Name>';` to `index.ts` in the existing style (one block per component, in order).
- **Props.** `interface <Name>Props extends Omit<ComponentPropsWithoutRef<'element'>, 'conflicting' | 'keys'>`; every schema prop is a documented field with a JSDoc line taken from the schema description. Enum props whose values are digit strings also accept the number. `content` props are `ReactNode`. Function/array props use the schema `shape` verbatim; export the item type (`RadioGroupOption`, `BreadcrumbItem`).
- **Ids.** `useId()` for every generated id; `aria-describedby` joins description and error ids.
- **Styling.** `import './<Name>.css'` (typed by `css.d.ts`). Class names `ds-<name>`, elements `ds-<name>__<part>`, modifiers `ds-<name>--<value>`. Every visual value is `var(--<token-kebab>)`; interpolated bindings become one modifier class per enum value (`.ds-button--primary { background: var(--color-action-primary-background) }`). No hex/px/ms/font literals — `tools/lint_literals.py` fails the build. The visually-hidden clip pattern (1px) and `color-mix()` of tokens are the sanctioned exceptions; anything else needs `/* literal-ok: reason */`.
- **Overrides.** Every style binding is a CSS custom-property hook on the root, `--ds-<name>-<binding>` (kebab), defaulting to its token; rules read the hook. `overrides?: Partial<Record<OverridableBinding, TokenRef>>` (`import type { TokenRef } from '@design-schema/tokens'`, `cssVar(ref)` from the same package) writes hooks inline; locked bindings (listed in the prompt) are excluded from the type.
- **Spacing between siblings** is never a margin: Stack `gap` (`layout.gap.*`), Box/Card `inset` (`layout.inset.*`), Container gutters. A resolved token path ending in `.default` drops it (`--color-background`).
- **States.** `disabled` → `aria-disabled="true"` + the element stays focusable; on checkable inputs also `preventDefault()` in `click` and `change`. `:focus-visible` outline `var(--border-width-focus) solid var(--color-border-focus)`. Transitions use the component's `transition` token with `var(--motion-easing-standard)` and are removed under `@media (prefers-reduced-motion: reduce)`. Disabled dims with `var(--opacity-disabled)`.
- **Form fields** register with `FormContext` (`useFormContext()`): `{ name, label, id, getValue, validate, focus }`; `getValue` returns `string | boolean | undefined` (undefined = omitted). Validation precedence: `error` prop → `required` (`copy.required`) → `invalid` (`copy.invalid`), with `{label}` replaced by the visible label. `validate: blur` means on-change for toggles.
- **Copy** strings from the schema are constants used verbatim (`const COPY = { required: '{label} is required.' }`).
- **Composition.** Use `Button`, `Link`, `Text`, `Icon` from the package; never restyle a child (no class overrides). Icons go through `Icon` (`<Icon name="check" inline />`) or a component's `leadingIcon` prop.
- **Dev warnings** are guarded by `process.env.NODE_ENV !== 'production'` (a `declare const process` shim is acceptable).
- **Stories.** CSF3, `import type { Meta, StoryObj } from '@storybook/react'`, `title: '<Name>/React'`, `Default` plus one story per enum value named `<Prop><Value>` (`ToneInfo`), plus notable states. `tags: ['autodocs']`. Demos live in `packages/react/demo/` with `title: 'Demo/<Name>/React'`.
- **Theming** is external: the app loads `@design-schema/tokens/calm-precise/css` once and toggles `data-mode="dark"` on `<html>`; components contain no theme logic.
- **Testability hook.** The root element carries `data-ds="<Name>"`. Components generated before this convention lack it; add it to any file you touch, and never rely on its absence.
- **Parts and props.** `data-part` values are the anatomy names verbatim (`headerActions`, not `header-actions`); a part drawn as a pseudo-element has no hook. `...rest` never forwards `style` or `className` to the root — the override contract is the only per-instance styling. An override for a composed child's binding is forwarded to that child's `overrides` (Fieldset → Stack `gap`, Divider → Text `fontSize`, Alert → Icon `color`/`size`), never applied as CSS on the child.
